# Support

## Getting Help

Before asking for help, check:

- `README.md`
- Release notes
- Existing GitHub Issues
- Existing discussions, if enabled

## Bug Reports

Use GitHub Issues for reproducible bugs.

Include:

- Saudade version or commit.
- Operating system.
- Python version.
- PyTorch version.
- Hardware when relevant.
- Command used.
- Full error message or traceback.
- Minimal reproduction steps.

## Generation Problems

For unexpected model output, include:

- Model/checkpoint version.
- Prompt.
- Temperature.
- Top-k.
- Top-p.
- Repetition penalty.
- Greedy setting.
- Number of generated tokens.
- Output produced.

## Training Problems

Include:

- Model configuration.
- Dataset/tokenizer version.
- Training step.
- Tokens seen.
- Batch size.
- Learning rate.
- Hardware.
- Relevant logs.

Do not upload private datasets, credentials, API keys, or other sensitive information.

## Feature Requests

Use GitHub Issues for feature requests. For large architectural changes, discuss the idea before implementing it.
